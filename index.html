Market data platform

Backend

A backend on Supabase and PostgreSQL that pulls live pricing from a market API, scores contracts against several models and publishes the results to a public dashboard.

  • 20 Deno and TypeScript edge functions, 37 SQL migrations, all scheduled through cron jobs
  • Test suite across 10 files, so scoring logic fails loudly instead of returning quiet bad numbers
  • Traced intermittent production 500s to the SQL view behind the main query and rewrote it

Luna Store catalog

Front-end

A product catalog for a small import business in Venezuela, running on a custom domain with a Spanish-language interface that the owner can read and share from a phone.

  • Static site with client-side search and category filters across 58 products
  • Direct WhatsApp handoff from any product, which is how the orders actually arrive
  • Images normalized to one catalog standard, cutting file size roughly in half

Summit Trails

Front-end

A responsive hiking guide with a light and dark theme the visitor can switch, built with CSS Grid and Flexbox and no framework.

  • Theme choice stored in localStorage, falling back to the system preference
  • Sections revealed through IntersectionObserver, staggered inside each grid
  • Every animation disabled under prefers-reduced-motion

Live site Repository

Visitor registration form

JavaScript

A single-page travel site whose form is validated entirely in plain JavaScript, with a separate validation library I wrote for it.

  • Required fields, two letter state, zip, phone and email, each with its own message under the field
  • Checks a field when you leave it and again on submit, keeping native form validity in sync
  • Code split into a validation library, a section router and an entry point

About

Accounting first, then code

I finished an accounting degree in Venezuela and spent years reconciling records and chasing numbers back to their source. That habit turned out to be the useful part: I check data against where it came from before I trust it, which is most of debugging.

Since 2023 I have worked at Nestlé as a maintenance technician, diagnosing equipment while the line is down and people are waiting. I learned to ask questions early instead of sitting on a problem until it gets expensive, and to write down what I did so the next person does not have to guess.

I am finishing a Computer Science degree at UVU and looking for an internship where I can learn from people who have been doing this longer than me.
